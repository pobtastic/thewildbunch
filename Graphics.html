Gunfight Character Sets

The street-fight sequence — BASIC lines 5019-5070 — re-points CHARS at four custom character sets above RAMTOP and PRINTs them as layered tiles to build the gunfight graphic. Each set is documented glyph-by-glyph at the addresses below; the sheets are the 96 glyphs from code 32 to 127.

Character set 2 (CHARS=F5F7; Gunfight_Charset_2)
Character set 3 (CHARS=F8F7; Gunfight_Charset_3)
Character set 4 (CHARS=FBFE; Gunfight_Charset_4)
Plot And Draw Art

Other pictures in the game — the town map flourishes, wanted-poster face, tombstone / badge endings, and so on — are drawn with BASIC PLOT / DRAW / CIRCLE, often from the coordinate tables at Plot_Points, Draw_Segments_Top_Grade and Draw_Segments_Ending. Those are vector sequences rather than bitmap tiles, so they are not shown as images here.
