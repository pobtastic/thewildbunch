
The Wild Bunch disassembly
==========================

A disassembly of the [Spectrum](https://en.wikipedia.org/wiki/ZX_Spectrum) game
[The Wild Bunch](https://en.wikipedia.org/wiki/The_Wild_Bunch_(video_game)).

The published game is mostly Sinclair BASIC with a small machine-code stub.
`LIST` is blocked after line 1; the recovered BASIC listing is on the HTML
**BASIC listing** page after you build.

Created using [SkoolKit](https://skoolkit.ca).

Browse the latest release:

* [The Wild Bunch disassembly](https://pobtastic.github.io/thewildbunch/) (hexadecimal; mirror [here](http://skoolkit.arcadegeek.co.uk/thewildbunch/))
* [The Wild Bunch disassembly](https://pobtastic.github.io/thewildbunch/dec/) (decimal; mirror [here](http://skoolkit.arcadegeek.co.uk/thewildbunch/dec/))

To build the current development version, first either install SkoolKit, or
make a clone of the [SkoolKit repository](https://github.com/skoolkid/skoolkit)
and point the environment variable SKOOLKIT_HOME at it. Then:

    $ utils/mkhtml.py
