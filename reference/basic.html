The commercial tape stores the program as a single PROGRAM block with a one-line stub that LIST will show, then the real tokenised program with line 15's header deliberately corrupted so listing stops. This page is a recovered LIST of that program (507 lines). Line 15 is reconstructed from the prompt text and the pre-production tape; every other line is taken from the post-load snapshot.
